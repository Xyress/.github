# Xyress

**Verifiable AI infrastructure.**

Xyress is verifiable AI infrastructure: a sovereign realm where humans, organizations, AI agents, and devices operate under unified identity, verifiable trust, and multi-model AI assistance. Built by [Ivalice](https://ivalice.com/).

One identity. Everything connected. Every action provable.

## The nine building blocks

| Tier | Component | What it does | Status |
|---|---|---|---|
| Foundation | **Sigil** | One identity for every person, company, AI system, and device | Phase 1 · in build |
| Foundation | **Witness** | Every action that matters recorded as evidence anyone can check | Phase 1 · in build |
| Application | **Vigil** | Continuous, AI-assisted security built into the platform | Phase 1 · in design |
| Application | **Commons** | How systems open their doors to each other, under rules each sets | Phase 1 · in design |
| Application | **Synod** | Several AI models work on important decisions together | Phase 1 · in design |
| Application | **Nexa** | Modernize an existing system or bring a new one onto Xyress | Phase 1 · in design |
| Application | **Charter** | Any system on Xyress can issue its own tokens | Phase 1 · v1 in design |
| Application | **Arbiter** | Ranks AI models on how they really perform | Phase 1 · in research |
| Application | **Retinue** | Platform-tuned AI agents that act within limits you set | Phase 1 · in research |
